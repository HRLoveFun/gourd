## 三、切分（阶段三）→ 闸门 A

对每一组候选内容问一句：**会不会被同一句用户请求同时需要？**

| 候选 skill | 被哪句话触发 | 能单独跑通吗 | 结论（建/合/不建） |
| --- | --- | --- | --- |
| | | | |

- 拆的判据：触发语不同、产出物不同、能独立跑通、一方高频
- 不拆的判据：只是材料章节不同、拆完要互相指路、只是详略不同

## 四、闸门检查

三个阶段各自停下来等确认，不可自行推进。

### 闸门 A（阶段三后）

- [ ] 归类表已填完，每条都有落点
- [ ] 判断规则已单独清点，每条都有归属
- [ ] 缺口清单已给用户，含"待填"的已确认
- [ ] 切分方案已给用户，每个 skill 附了一句触发语
- [ ] 用户已明确确认

### 闸门 B（阶段六后，写盘前）

- [ ] 目录树已给出（含哪些目录留空、哪些不建）
- [ ] 每份 `description` 已定稿，含边界
- [ ] 正文大纲对齐九节，已标出删节项及理由
- [ ] 500 行预算已估算
- [ ] 用户已明确确认

### 闸门 C（阶段八，落盘后）

- [ ] `./skills/skill-forge/scripts/lint-skill.sh <name>` 退出码 0
- [ ] 触发测试：真实说法命中，无关说法不命中
- [ ] 冷启动测试：交给子 Agent 跑通，或自检无"需回翻材料"处
- [ ] 失败测试：空输入 / 错格式 / 缺依赖 均有明确出口
- [ ] `CATALOG.md` 状态填对（三测全过才填 `可用`）
