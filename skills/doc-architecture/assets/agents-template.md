# AGENTS.md 骨架

> 用法：只拷 `---` 以下的内容到项目根，逐格替换，`<...>` 全部替换或整段删。删掉一段就不要留空标题。
> 五块顺序固定：定位 → 状态指针 → 地图指针 → 元规则 → 改动协议。
> 本文件是 agent 的**唯一入口**：`CLAUDE.md`、`.cursorrules` 等只做软链，不做第二个真文件。
> 指向地图用普通路径，不要写成 `@DOC_MAP.md`：`@` 导入会让地图每次会话都加载。
> 没有 `DOC_MAP.md` 时（文档不超出进门三件）：删掉「文档地图」一节，改动协议第 1、2 步换成：
> 「批次收尾改 `STATUS.md`，用法变化改 `README.md`，约定变化改本文件。」
> 「文档超出这三份就建 `DOC_MAP.md`。」


## 改动协议

1. 查该改哪份：`grep '【事件】' DOC_MAP.md`（事件换成词表里的修改事件），看“时改”那段，逐份更新。
2. 改文档结构：先改 `DOC_MAP.md`，再动文件。
3. 验收：`bash scripts/doc-check.sh` 退出码 0。
