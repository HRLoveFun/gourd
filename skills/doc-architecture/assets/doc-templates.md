# 文档骨架：STATUS / ARCHITECTURE / CONVENTIONS / ADR / L2

> 用法：按档位拷需要的几节，各存成独立文件。首部那一行元信息必须保留并改写，`doc-check.sh` 查它。
> 每份文档只在被地图指到时才建；建了就要能被回答，填不出内容就先别建。

---

## STATUS.md

```markdown
# 状态

> L1 | 权威：项目现状、批次进度、已知未完成 | 不权威：结构、约定、决策理由

当前焦点：<一句话，指到具体批次或问题；没有就写「无」>

## 批次

| 批次 | 目标 | 状态 | 证据 | 更新日期 |
| --- | --- | --- | --- | --- |
| F0 | <目标一句话> | 未开始 | - | <YYYY-MM-DD> |

状态取值：`未开始` / `进行中` / `已完成` / `受阻` / `已取消`。
`已完成` 的证据列必须填：路径、可复跑命令、commit/PR 三者之一；填不出只能写 `进行中（待验证）`。

## 已知未完成

- <一句话 + 指向 docs/plans/ 的路径>

## 已知风险

- <一句话 + 触发条件>
```
